# Release Notes - Sonara v1.0.0

Welcome to the first stable release of Sonara!

## What's New
- **Strict Offline Playback**: Complete support for local MP3, FLAC, and WAV audio files.
- **Material You Engine**: Dynamic coloring extracting palette from current playing album art.
- **Advanced Equalizer**: 10-band equalizer and pre-configured audio profiles.
- **Play Integrity Validation**: Security systems built-in to prevent malicious alterations.
- **Background Sync Engine**: Playlist and metadata synchronization powered by WorkManager.

## Fixes & Improvements
- Fixed manifest XML parsing and Android 14 target compliancy.
- Upgraded to latest Room DB schema.
- Re-architected UI performance for 120Hz displays.
