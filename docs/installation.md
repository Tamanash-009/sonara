# Installation Guide

To install the Sonara Music application, you have two primary options:

## Option 1: Direct APK Installation
1. Download the latest `sonara-release.apk` from the [Releases](https://github.com/yourusername/sonara/releases) page.
2. Transfer the APK to your Android device.
3. Open your device Settings > Security (or Biometrics and Security) and enable "Install Unknown Apps" for your file manager.
4. Tap the APK file to install the application.

## Option 2: Build from Source
1. Clone the repository: `git clone https://github.com/yourusername/sonara.git`
2. Open the project in Android Studio Iguana or newer.
3. Connect your Android device via USB debugging or start an emulator.
4. Click "Run > Run 'app'" in Android Studio.

## Requirements
- Android 8.0 (API level 26) or higher.
- Storage permission to scan and manage local music libraries.
